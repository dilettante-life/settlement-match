# Settlement Match

A tool that helps people find open class action settlements they actually qualify for, and shows whether they'll need proof to file a claim.

## Status

Early stage. I'm learning Python and Git from scratch. One day, or day one.

## The problem

Class action settlements set aside money for consumers every year, but many eligible people never file a claim. Settlement notices are long, written in legal language, and spread across dozens of different websites, so figuring out which ones apply to you takes real effort.

## Planned features

- **Eligibility questionnaire:** users answer a few simple questions, and the tool matches them against open settlements.
- **AI document reading:** AI reads each official settlement notice and pulls out who qualifies, the claim deadline, and whether proof is required.
- **Citations:** every match shows the exact sentence from the official notice that supports it, so users can verify it themselves.
- **Official links only:** claim links go to the settlement administrator's official website, never third-party pages.
- **Accuracy testing:** I'll hand-check a sample of settlements to measure how often the AI gets eligibility right, and improve it from there.

## Privacy by design

Users share only what they choose to enter in the questionnaire. The tool is designed never to track browsing activity or store sensitive personal information, and it never files claims on anyone's behalf.
